# SEO & Digital Marketing Agency Website

A modern, responsive, and visual landing page designed for a **Digital Marketing, SEO Tools & Project Management Agency**. Built with clean HTML5, CSS3, and modern web development best practices to ensure seamless layout presentation across desktop, tablet, and mobile devices.

---

## 🌟 Key Features

* **Hero Section:** High-impact heading with engaging visuals and call-to-action (CTA) buttons.
* **Services Overview:** Clean grid showcase of agency services including SEO optimization, project strategy, and digital marketing tools.
* **Stats & Metrics Display:** Visual counter/stats section highlighting key achievements (e.g., active projects, satisfied clients, team size).
* **Portfolio & Case Studies:** Interactive portfolio grid/carousel displaying client work and successful case studies.
* **Pricing Plans:** Transparent tiered pricing cards (Basic, Standard, Advanced) with highlighted feature lists and subscription buttons.
* **SEO Audit Tool / Newsletter Subscription:** Quick email input section for users to request an instant website SEO score.
* **Video & Media Gallery:** Interactive video section with tabbed media previews.
* **Contact & Map Integration:** Working contact form UI alongside embedded Google Maps layout for location awareness.
* **Footer Section:** Organized link structures, social media quick links, and copyright info.

---

## 🛠️ Tech Stack & Technologies Used

* **HTML5:** Semantic structure for optimal SEO and accessibility.
* **CSS3:** Custom styling, Flexbox/Grid layouts, gradients, subtle animations, and responsive media queries.
* **JavaScript (Vanilla / ES6+):** Interactive UI elements, dynamic tabs, smooth scrolling, and form validation.
* **FontAwesome / LineIcons:** Clean modern UI icons.
* **Google Fonts:** Clean, readable typography.
